# 文字绳子交互效果（Text Rope Effect）

把一段文字变成一条可拖拽的"物理绳子"：文字像绳子一样串联在一起，拖拽任意字符像拉绳子一样把整串拉散；按 `F` 键让文字在重力作用下自然散落，按 `R` 键缓动飞回原位重新排列。

## 快速体验

直接用浏览器打开 `index.html` 即可。

## 特性

- **Verlet 积分物理模拟** —— 位置式积分（velocity-less），比欧拉积分更稳定
- **距离约束迭代**（12 次/帧）—— 保持蛇形相邻字符的"绳子连接感"
- **蛇形排列（Zig-Zag）** —— 物理连接顺序与视觉阅读顺序分离
- **SVG 绳子连线** —— 字符间连线实时跟随，绷紧/松弛直观可见
- **Pointer Events** —— 统一鼠标 / 触摸拖拽
- **拉断解锁传播** —— 拖远超过阈值自动解锁相邻字符，连锁"拉绳子"
- **F 键解开散落 / R 键一键恢复 / 窗口自适应重排**
- **绳子可见性开关** —— `V` 键或底部按钮随时显示/隐藏连线
- **自定义诗句** —— 底部输入框输入任意文本，回车或点"应用"立即重建

## 使用与定制

修改文件顶部 `CONFIG` 对象即可，无需改动物理代码：

| 参数 | 默认 | 说明 |
|---|---|---|
| `TEXT` | 桃花源记 | 要展示的文本（中文/英文均可） |
| `MAX_WIDTH` | 900 | 一行最大宽度（px），决定分行 |
| `FONT_SIZE` / `LINE_HEIGHT` | 22 / 1.6 | 字号与行高 |
| `GRAVITY` / `DAMPING` | 0.15 / 0.97 | 重力与速度阻尼 |
| `ITERATIONS` / `RADIUS` | 12 / 8 | 约束迭代次数 / 碰撞半径 |
| `UNLOCK_THRESHOLD` | 18 | 拉断解锁阈值 |
| `RESTORE_SPEED` | 0.14 | R 键恢复动画速度 |
| `SHOW_ROPE` | true | 绳子连线初始可见性（运行时 V 键/按钮可切换） |

## 技术原理

- Verlet 积分：`速度 = 当前位置 - 上一帧位置`，乘以阻尼后应用位移与重力
- 距离约束：每帧迭代 12 次，按锁定状态推动一端或双方，把相邻字符拉回静止绳长
- 蛇形排列：奇数行反转构成物理顺序，每个字符记录 `readingIdx` 保持视觉阅读顺序
- 碰撞检测：圆形分离，跳过蛇形相邻对
- 固定时间步长：120Hz 物理循环 + rAF 渲染，保证不同刷新率下表现一致
